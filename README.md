## 怎么跑

需要 JDK 21 或更高：

```bash
cd hello
javac Hello.java
java Hello
```

每个目录都是独立的小项目，进去单独编译运行，互不依赖。

---

## 我在练什么

每个目录 = 一个能跑起来的小东西，做完一个提交一次。

提交信息写「**做了什么 + 学到了什么**」，不写 `update` / `修改` / `1`。

```
好：feat(ledger): 用 try-with-resources 写文件，避免句柄泄漏
差：update
```

---

## 三条原则

1. **只走一条路**：Java 后端，不纠结 Python / Go / 前端
2. **看视频时间 ≤ 写代码时间的 1/3**：看 10 分钟 → 关掉 → 自己敲 20 分钟
3. **每天 30 分钟就算达标**：能坚持三周再谈加量
